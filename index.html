3.2 — Espacio Vectorial (EV)
Definición · 8 Axiomas · Ejemplos · Proposiciones
Definición 3.2.1 — Espacio Vectorial Real
Un espacio vectorial real es un sistema ⟨V, +, {Pₖ}⟩ formado por un conjunto V ≠ ∅, una operación suma + y productos por escalares k·, tales que se verifican los 8 axiomas para todo ū, v̄, w̄ ∈ V y k, h ∈ ℝ.
EV1
Asociativa suma: (ū+v̄)+w̄ = ū+(v̄+w̄)
EV2
Conmutativa suma: ū+v̄ = v̄+ū
EV3
Vector neutro: ∃ 0̄ ∈ V tal que ū+0̄=ū
EV4
Opuesto: ∃ (−ū) ∈ V tal que (−ū)+ū=0̄
EV5
Distrib. vectores: k·(ū+v̄) = k·ū + k·v̄
EV6
Distrib. escalares: (k+h)·ū = k·ū + h·ū
EV7
Asoc. mixta: (k·h)·ū = k·(h·ū)
EV8
Neutro producto: 1·ū = ū

Proposición 3.2.1 — Propiedades que siempre valen

Si V es EV, v̄ ∈ V y k ∈ ℝ, entonces:
i) 0 · v̄ = 0̄     ii) k · 0̄ = 0̄     iii) −(k·v̄) = (−k)·v̄ = k·(−v̄)
iv) k·v̄ = 0̄ implica k=0 ó v̄=0̄     v) si v̄+v̄=v̄ entonces v̄=0̄     vi) 0̄ es único
Para demostrar que algo NO es EV: encontrá UN axioma que falle. El más rápido de verificar es EV3 (buscar si 0̄ ∈ V). Si no está → ¡no es EV, listo!
3.4 — Subespacio Vectorial (SEV)
Definición · Teorema 3.4.1 (3 condiciones) · SG[A] · Proposiciones
Definición 3.4.1
S es subespacio de V (S ◁ V) si S ⊂ V y S también es un espacio vectorial con las operaciones de V.
Notación: S ◁ V = "S es subespacio de V". Si no es subespacio: S ⋪ V
✅ Teorema 3.4.1 — RECETA: S ES subespacio (3 condiciones)
  1. Trabajar la expresión de los elementos de S: despejar variables dependientes en función de las libres
  2. Expresar como combinación lineal de vectores fijos: S = SG{v̄₁, v̄₂,...} — esto ya prueba que es subespacio por Teorema 3.4.3
  3. Si el libro pide la demostración completa, demostrar las 3 tesis:
    • Tesis 1 0̄ ∈ S → tomar todos los parámetros = 0
    • Tesis 2 ū, v̄ ∈ S ⟹ ū+v̄ ∈ S (cerrado bajo suma)
    • Tesis 3 ū ∈ S, k ∈ ℝ ⟹ k·ū ∈ S (cerrado bajo prod. escalar)
  4. Concluir: S ◁ V
Atajo máximo: si podés escribir S = SG{v̄₁,...,v̄ₚ} → por Teorema 3.4.3 → S es subespacio. Listo. No hace falta verificar las 3 condiciones.
❌ RECETA: S NO ES subespacio (contraejemplo)

Basta mostrar UNA cosa que falla:

  1. Verificar 0̄ ∉ S: sustituir (0,0,...,0) en la condición del conjunto. Si no la satisface → fin.
  2. Violar Tesis 2: tomar ū, v̄ ∈ S y mostrar que ū+v̄ ∉ S
  3. Violar Tesis 3: tomar ū ∈ S, un k ∈ ℝ y mostrar que k·ū ∉ S
Ejemplo del libro (Ej. 3.4.5)
U = {(x,y,z) | x−y+2z=4}. Verificar (0,0,0): 0−0+0=0 ≠ 4. Entonces 0̄ ∉ U → U ⋪ ℝ³. (Sistema no homogéneo → nunca es subespacio)

Proposición 3.4.1 y 3.4.2 — Regla de Sistemas

Proposiciones de Sistemas

SÍ es SEV El conjunto solución de un sistema homogéneo (A·X=θ) SIEMPRE es subespacio de Mₙₓ₁.

NO es SEV El conjunto solución de un sistema no homogéneo (A·X=H, H≠θ) NUNCA es subespacio (porque 0̄ no lo satisface).

3.4.1 — Espacio Lineal Generado SG[B]
Definición 3.4.2: Dado B={ū₁,...,ūₙ} ⊂ V:
SG[B] = {v̄ ∈ V | ∃c₁,...,cₙ ∈ ℝ tales que c₁ū₁+...+cₙūₙ=v̄}
= todas las combinaciones lineales posibles de los vectores de B.
RECETA: Hallar SG[B] — encontrar la condición/ecuación del subespacio
  1. Plantear c₁ū₁+...+cₙūₙ = (a,b,c,...) = vector genérico
  2. Armar la matriz [ū₁|...|ūₙ|(a,b,c,...)] y escalonar
  3. Para que existan los cᵢ se necesita rg(A)=rg(A*)
  4. La condición que garantiza rg(A)=rg(A*) es la ecuación de SG[B]
Ejemplo del libro (Ej. 3.4.6)
B={(1,1,1),(2,1,0)} en ℝ³. Después de escalonar, la condición resulta: a−2b+c=0.
Por tanto SG[B] = {(a,b,c) ∈ ℝ³ | a−2b+c=0}
Si después de escalonar la condición se cumple SIEMPRE (sin restricción), entonces SG[B] = el espacio completo (el conjunto genera todo el espacio).
Teorema 3.4.4
Si v̄ es combinación lineal de los vectores de S, entonces SG[S ∪ {v̄}] = SG[S]. Agregar un vector que ya es CL de los demás no amplía el espacio generado.
3.3 y 3.5.1 — Combinación Lineal · LI · LD
Definiciones · Recetas completas · Lemas y Teoremas del libro
Combinación Lineal — Def. 3.3.1
v̄ es CL de {ū₁,...,ūₙ} si existen c₁,...,cₙ ∈ ℝ tales que: c₁·ū₁ + c₂·ū₂ + ... + cₙ·ūₙ = v̄
✅ RECETA: v̄ SÍ es CL de {ū₁,...,ūₙ}
  1. Plantear la ecuación vectorial: c₁·ū₁ + ... + cₙ·ūₙ = v̄
  2. Armar sistema componente a componente → forma matricial [ū₁|...|ūₙ] · X = v̄
  3. Armar la matriz ampliada [ū₁|...|ūₙ|v̄] y escalonar (Gauss)
  4. Si rg(A) = rg(A*) → sistema compatible → v̄ SÍ es CL
  5. Calcular los valores de c₁,...,cₙ
  6. VERIFICAR: sustituir y comprobar que c₁·ū₁+...+cₙ·ūₙ = v̄ ✓
Ejemplo 3.3.1 del libro
v̄=(5,3), ū₁=(1,2), ū₂=(3,−1). Sistema: c₁+3c₂=5 y 2c₁−c₂=3.
Escalonando: c₂=1, c₁=2. Verificación: 2·(1,2)+1·(3,−1)=(2,4)+(3,−1)=(5,3) ✓
❌ RECETA: v̄ NO es CL
  1. Mismo procedimiento que arriba
  2. Si rg(A) ≠ rg(A*) → sistema incompatible → v̄ NO es CL
  3. Concluir: no existen c₁,...,cₙ que satisfagan la ecuación
0̄ SIEMPRE es CL de cualquier conjunto (tomando todos los cᵢ = 0). Proposición 3.3.1.
Independencia / Dependencia Lineal — Def. 3.5.1
LI (linealmente independiente): c₁·v̄₁+...+cₙ·v̄ₙ=0̄ tiene única solución: c₁=...=cₙ=0 (solución trivial)

LD (linealmente dependiente): la misma ecuación tiene infinitas soluciones (existe algún cᵢ≠0)
RECETA: Determinar si {v̄₁,...,v̄ₙ} es LI o LD
  1. Plantear: c₁·v̄₁ + c₂·v̄₂ + ... + cₙ·v̄ₙ = 0̄
  2. Armar el sistema homogéneo [v̄₁|...|v̄ₙ] · X = θ
  3. Escalonar la matriz de coeficientes
  4. Calcular nro de variables libres = n − rg(A)
       → nro.vl = 0: única solución (trivial) → LI
       → nro.vl > 0: infinitas soluciones → LD
  5. Si LD: hallar una solución no trivial y escribir un vector como CL de los demás
Ejemplo 3.5.1 del libro (LI)
A={(1,1,1),(5,5,2),(3,2,1)}. Matriz escalonada tiene rg=3, nro.vl=0 → LI ✓
Ejemplo 3.5.2 del libro (LD)
B={(1,1,1),(3,2,1),(−3,−1,1)}. Matriz escalonada tiene rg=2, nro.vl=1 → LD.
Solución no trivial c₃=1: −3·(1,1,1)+2·(3,2,1)+1·(−3,−1,1)=(0,0,0) ✓

Lema 3.5.2 — Atajos rápidos para LD

Lema 3.5.2

1. Si 0̄ ∈ T → T es LD. (El vector nulo en el conjunto → siempre LD)

2. Si {ū, v̄} ⊂ V → es LD ⟺ ū = k·v̄ para algún k ∈ ℝ (uno es múltiplo del otro)

Teorema 3.5.1
Un conjunto S es LD ⟺ algún vector de S es CL de los demás. (Bidireccional: LD⟺hay un vector dependiente)
Teorema 3.5.2
Si se tienen más vectores que la dimensión del espacio → siempre LD. (p vectores en ℝⁿ con p>n → LD)
3.5.2 — Base, Dimensión y Coordenadas
Definiciones · Proposiciones · Bases canónicas · Coordenadas
Definición 3.5.2 — Base
α es base de V si y solo si:
(1) α ⊂ V     (2) α es LI     (3) SG[α] = V
RECETA COMPLETA: Demostrar que α es BASE de V
  1. Verificar α ⊂ V (los vectores pertenecen al espacio)
  2. Demostrar LI: sistema homogéneo → solo solución trivial (escalonar, rg=n)
  3. Demostrar SG[α]=V: mostrar que todo vector de V es CL de α → sistema compatible para todo vector genérico
  4. Concluir: α es base de V, dim(V) = |α|
Proposición 3.5.2 (atajo): Si dim(V)=n y tengo exactamente n vectores que SON LI → automáticamente es base (sin verificar generación). O viceversa: si tengo n vectores que GENERAN → también es base automáticamente.

Coordenadas — Def. 3.5.6
Si α={v̄₁;...;v̄ₙ} es base ordenada de V y ū=k₁·v̄₁+...+kₙ·v̄ₙ, entonces:
• Coordenadas: k₁, k₂, ..., kₙ
• Vector de coordenadas: (ū)α = (k₁,...,kₙ)
• Matriz de coordenadas: [ū]α = columna con k₁,...,kₙ
RECETA: Hallar coordenadas de ū respecto a base α
  1. Plantear: k₁·v̄₁ + k₂·v̄₂ + ... + kₙ·v̄ₙ = ū
  2. Resolver el sistema de ecuaciones (igual que CL)
  3. Los kᵢ hallados son las coordenadas: (ū)α = (k₁,...,kₙ)
Ejemplo 3.5.11 del libro
En ℝ², α={(1,1);(−1,1)}, w̄=(1,5).
Sistema: c₁−c₂=1 y c₁+c₂=5 → c₁=3, c₂=2.
(w̄)α = (3,2). Verificar: 3·(1,1)+2·(−1,1) = (3,3)+(−2,2) = (1,5) ✓
Con la base canónica: (ū)C = ū (las coordenadas son las componentes habituales).
3.5.3 — Cambio de Base
Matriz de paso · Teoremas 3.5.5 y 3.5.6
Matriz de Paso — Def. 3.5.7
Definición 3.5.7: Sean α={ū₁;...;ūₙ} y β={v̄₁;...;v̄ₙ} bases ordenadas de V.
La Matriz de Paso de α a β es la matriz MP ∈ Mₙₓₙ cuyas columnas son [ūᵢ]β (las coordenadas de cada vector de α expresadas en la base β).
MP = [ [ū₁]β | [ū₂]β | ... | [ūₙ]β ]
Teorema 3.5.5 — Cómo usar MP
Para todo w̄ ∈ V: [w̄]β = MP · [w̄]α
(Para pasar de coordenadas en α a coordenadas en β: multiplicar por MP)
Teorema 3.5.6 — Inversa de MP
Si MP es la matriz de paso de α a β, entonces inv(MP) es la matriz de paso de β a α.
RECETA: Cambio de base (Ejemplo 3.5.12)
  1. Para cada ūᵢ de α: resolver el sistema c₁·v̄₁+...+cₙ·v̄ₙ=ūᵢ → hallar [ūᵢ]β
  2. Armar MP poniendo los [ūᵢ]β como columnas (se puede resolver simultáneamente con la misma matriz A)
  3. Para hallar [w̄]β dado [w̄]α: calcular [w̄]β = MP · [w̄]α
  4. Para hallar w̄ en ℝⁿ: expresar usando cualquiera de las dos bases
Ejemplo 3.5.12 del libro
α={(4,3);(−5,5)}, β={(1,2);(−2,1)} en ℝ².
Resolviendo: [ū₁]β=(2,−1), [ū₂]β=(1,3) → MP=[[2,1],[−1,3]]
Dado [w̄]α=(−2,5): [w̄]β = [[2,1],[−1,3]]·(−2,5) = (1,17) → w̄=(−33,19)
Cap. 4 — Producto Interno y Normas
Producto euclídeo · Propiedades · Normas 1, 2, ∞ · Unitarización · Ángulo · Cauchy-Schwarz
4.1 — Producto Euclídeo (Producto Interno)
Definición 4.1.1: Si β es base ordenada de V, el producto euclídeo de ū y v̄ es:
⟨ū,v̄⟩β = [ū]ᵀβ · [v̄]β = u₁v₁ + u₂v₂ + ... + uₙvₙ
⟨ū,v̄⟩ = Σᵢ uᵢ·vᵢ (suma de productos componente a componente)
El producto euclídeo depende de la base elegida. Con la base canónica: simplemente multiplicar componentes y sumar.
Ejemplo 4.1.1 del libro
ū=(2,5,3), v̄=(1,3,3) en ℝ³ (base canónica):
⟨ū,v̄⟩C = 2·1 + 5·3 + 3·3 = 2+15+9 = 26
Con base β={(1,2,0);(0,1,3)}: (ū)β=(2,1), (v̄)β=(1,1) → ⟨ū,v̄⟩β = 2·1+1·1 = 3 (resultado diferente)

4.2 — Normas
Norma es una función µ:V→ℝ que satisface: N1) µ(ū)≥0 (=0 solo si ū=0̄); N2) µ(k·ū)=|k|·µ(ū); N3) µ(ū+v̄)≤µ(ū)+µ(v̄) [desigualdad triangular]

Las 3 Normas frecuentes

‖(ū)β‖₁ = |c₁| + |c₂| + ... + |cₙ| (suma de valores absolutos) ‖(ū)β‖₂ = √(c₁² + c₂² + ... + cₙ²) (euclídea) ‖(ū)β‖∞ = máx{|c₁|, |c₂|, ..., |cₙ|} (Tchebychev)
donde (cᵢ) son las coordenadas de ū respecto a la base β dada.

Vector Unitario — Def. 4.2.3

ū es unitario si ‖ū‖ = 1.
Para unitarizar cualquier vector ū≠0̄:
ê₁ = ū/‖ū‖ (positivo) ê₂ = −ū/‖ū‖ (negativo)
De cualquier vector no nulo se obtienen EXACTAMENTE 2 vectores unitarios: ū/‖ū‖ y −ū/‖ū‖.
Ejemplo 4.2.1 del libro
P={x+y+z=0}, β={(1,2,0),(0,1,3)}, ū=(2,5,3), [ū]β=(2,1):
‖(ū)β‖₁ = |2|+|1| = 3    ‖(ū)β‖₂ = √(4+1) = √5    ‖(ū)β‖∞ = máx{2,1} = 2

Ángulo entre vectores — Def. 4.2.4

cos(θ) = ⟨ū,v̄⟩β / (‖(ū)β‖₂ · ‖(v̄)β‖₂)
ū ⊥ v̄ (ortogonales) ⟺ ⟨ū,v̄⟩ = 0 ⟺ θ = 90°
Teorema 4.2.2 — Desigualdad de Cauchy-Schwarz
Para todo ū,v̄ ∈ V:    |⟨ū,v̄⟩β| ≤ ‖(ū)β‖₂ · ‖(v̄)β‖₂
4.3 y 4.4 — Ortogonalidad y Gram-Schmidt
Conjuntos ortogonales · Ortonormales · Proyección ortogonal · Proceso Gram-Schmidt
Ortogonal vs Ortonormal
TipoCondiciónLema relacionado
Ortogonal⟨v̄ᵢ,v̄ⱼ⟩ = 0 para todo i≠jTeorema 4.3.1: ortogonal y sin 0̄ → automáticamente LI
Ortonormal⟨v̄ᵢ,v̄ⱼ⟩ = 0 si i≠j, y ⟨v̄ᵢ,v̄ᵢ⟩ = 1 (unitarios)
Verificar que un conjunto es ortogonal = calcular todos los productos ⟨v̄ᵢ,v̄ⱼ⟩ para i≠j y ver que sean 0.
RECETA: Verificar si β es BASE ORTONORMAL
  1. Calcular ⟨v̄ᵢ,v̄ⱼ⟩ = 0 para todo i≠j → ortogonal
  2. Calcular ‖v̄ᵢ‖ = 1 para todo i → unitarios
  3. Si cumple 1 y 2: conjunto ortonormal → por Teo. 4.3.1 es LI → si tiene dim(V) vectores → es base
  4. Verificar que los vectores ∈ V (cumplan la ecuación del subespacio)
Proyección Ortogonal
Proyección sobre vector unitario v̄ (‖v̄‖=1):
Proyv̄(ū) = ⟨ū,v̄⟩ · v̄
Si v̄ no es unitario (general):
Proyv̄(ū) = (⟨ū,v̄⟩/‖v̄‖²) · v̄
Proyección sobre W = SG{v̄₁,v̄₂} (ortonormales):
ProyW(ū) = ⟨ū,v̄₁⟩·v̄₁ + ⟨ū,v̄₂⟩·v̄₂

El complemento ortogonal: w̄ = ū − ProyW(ū) es ⊥ a todo elemento de W

4.4.4 — Proceso de Gram-Schmidt

Dado α={ū₁,...,ūₙ} LI, construir β={v̄₁,...,v̄ₙ} ortonormal con SG[α]=SG[β]

PASO 1: w̄₁ = ū₁ v̄₁ = w̄₁ / ‖w̄₁‖ PASO 2: w̄₂ = ū₂ − ⟨ū₂,v̄₁⟩·v̄₁ v̄₂ = w̄₂ / ‖w̄₂‖ PASO 3: w̄₃ = ū₃ − ⟨ū₃,v̄₁⟩·v̄₁ − ⟨ū₃,v̄₂⟩·v̄₂ v̄₃ = w̄₃ / ‖w̄₃‖ PASO i: w̄ᵢ = ūᵢ − Σₖ₌₁ⁱ⁻¹ ⟨ūᵢ,v̄ₖ⟩·v̄ₖ v̄ᵢ = w̄ᵢ / ‖w̄ᵢ‖
Cada w̄ᵢ = vector original MENOS sus proyecciones sobre todos los anteriores ya ortogonalizados y normalizados. Si en algún paso w̄ᵢ=0̄, los vectores originales eran LD y no se puede continuar.
Ejemplo 4.4.5 del libro
α={(−1,1,0),(−1,0,1)} base de A={x+y+z=0}:
Paso 1: ‖ū₁‖=√2, v̄₁=(−1/√2, 1/√2, 0)
Paso 2: ⟨ū₂,v̄₁⟩=1/√2 → w̄₂=(−1,0,1)−(1/√2)·v̄₁=(−1/2,−1/2,1) → ‖w̄₂‖=√6/2
v̄₂=(−1/√6,−1/√6,2/√6). Base ortonormal β={v̄₁,v̄₂} ✓
El proceso Gram-Schmidt SOLO funciona con vectores LI. Si el conjunto es LD, en algún paso w̄ᵢ=0̄ y hay que parar.
Coordenadas con base ortonormal — Teorema 4.4.1
Teorema 4.4.1 — Atajo para coordenadas
Si β={v̄₁;...;v̄ₙ} es base ortonormal, entonces las coordenadas de ū se calculan directamente:
(ū)β = (⟨ū,v̄₁⟩, ⟨ū,v̄₂⟩, ..., ⟨ū,v̄ₙ⟩)
Solo válido para bases ORTONORMALES. Si la base no es ortonormal, hay que resolver el sistema habitual.

4.5 — Producto Vectorial ū × v̄
Def. 4.5.1: ū × v̄ es el vector tal que: (1) ‖ū×v̄‖ = ‖ū‖·‖v̄‖·sen(α); (2) perpendicular al plano de ū y v̄; (3) sentido del "tirabuzón".
ū×v̄ = det | ē₁ ē₂ ē₃ | con ū=(u₁,u₂,u₃), v̄=(v₁,v₂,v₃) | u₁ u₂ u₃ | | v₁ v₂ v₃ | Expandiendo por la primera fila: ū×v̄ = (u₂v₃−u₃v₂, u₃v₁−u₁v₃, u₁v₂−u₂v₁)
Ejemplo 4.5.1 del libro

5.2 — Transformaciones Lineales (TL)
Definición · Receta de verificación · Ejemplos del libro · Efectos geométricos
Definición 5.2.1
T: V→W es TL si para todo ū,v̄ ∈ V y h ∈ ℝ:
T(ū + h·v̄) = T(ū) + h·T(v̄)
Equivalentemente (dos condiciones por separado):
(1) Aditividad: T(ū+v̄) = T(ū)+T(v̄)
(2) Homogeneidad: T(k·ū) = k·T(ū)
✅ RECETA: Demostrar que T ES TL
  1. Tomar ū=(x₁,y₁,...), v̄=(x₂,y₂,...) ∈ V arbitrarios y h ∈ ℝ arbitrario
  2. Calcular ū+h·v̄ = (x₁+hx₂, y₁+hy₂,...) y luego T(ū+h·v̄)
  3. Calcular T(ū) y T(v̄) por separado, luego T(ū)+h·T(v̄)
  4. Mostrar que los resultados de (2) y (3) son iguales → ES TL
Ejemplo 5.2.1 del libro — R(x,y)=(−y,x)
ū=(x₁,y₁), w̄=(x₂,y₂), k ∈ ℝ:
R(ū+kw̄) = R(x₁+kx₂, y₁+ky₂) = (−y₁−ky₂, x₁+kx₂)
R(ū)+k·R(w̄) = (−y₁,x₁)+k(−y₂,x₂) = (−y₁−ky₂, x₁+kx₂) ✓
❌ RECETA: Demostrar que T NO ES TL

Basta un contraejemplo. Estrategias por orden de velocidad:

  1. Más rápido: Calcular T(0̄). Si T(0̄) ≠ 0̄ → NO es TL (Teorema 5.2.1)
  2. Encontrar ū,v̄ con T(ū+v̄) ≠ T(ū)+T(v̄) (violar aditividad)
  3. Encontrar ū,k con T(k·ū) ≠ k·T(ū) (violar homogeneidad)
Ejemplo 5.2.2 del libro — S(x,y)=(x−3,y+2) NO es TL
S(0,0) = (−3,2) ≠ (0,0). Como T(0̄)≠0̄ → NO es TL. Listo.
Cuidado: T(0̄)=0̄ NO garantiza que sea TL (el recíproco no vale). Solo el caso negativo es concluyente.

5.3-5.4 — Transformación Matricial y Matriz Asociada
Definición · Teorema 5.4.1 · Cómo hallar la matriz
Def. 5.3.1 — Transformación Matricial
T: Mₙₓ₁→Mₚₓ₁ definida por T(X) = A·X (A ∈ Mₚₓₙ) es una transformación matricial. Toda transformación matricial ES TL (Teorema 5.3.1).
Teorema 5.4.1 — Matriz Asociada a T
Si T: V→W es TL, α={v̄₁,...,v̄ₙ} base de V, β={ū₁,...,ūₚ} base de W, entonces:
A = [[T(v̄₁)]β | [T(v̄₂)]β | ... | [T(v̄ₙ)]β]
(Las columnas son las imágenes de los vectores de la base α, expresadas en β)
RECETA: Hallar la matriz asociada [T]
  1. Identificar la base α del dominio (si no se especifica: base canónica)
  2. Calcular T(ē₁), T(ē₂), ..., T(ēₙ) (imágenes de cada vector de la base)
  3. Expresar cada imagen en la base β del codominio (si es canónica: son las componentes directamente)
  4. [T] = [T(ē₁) | T(ē₂) | ... | T(ēₙ)] (columnas = imágenes)
Ejemplo 5.4.2 del libro — R(x,y)=(−y,x)
R(1,0)=(0,1), R(0,1)=(−1,0)
[R] = [[0,−1],[1,0]] = [[R(1,0)] | [R(0,1)]]
Ejemplo 5.4.3 — F(x,y,z)=(2x−y, y−2z, x−y−z)
F(1,0,0)=(2,0,1), F(0,1,0)=(−1,1,−1), F(0,0,1)=(0,−2,−1)
[F] = [[2,−1,0],[0,1,−2],[1,−1,−1]]
5.6 — Imagen y Rango
Definición · Espacio imagen · Rango · Receta completa
Definiciones
Def. 5.6.1 — Imagen: T(V) = {T(v̄) | v̄ ∈ V} ⊆ W

Def. 5.6.2 (forma constructiva): Si β={v̄₁,...,v̄ₙ} es base de V:
T(V) = SG{T(v̄₁), T(v̄₂), ..., T(v̄ₙ)}

Def. 5.6.3 — Rango: r(T) = dim(T(V))
T(V) siempre es subespacio de W (Proposición 5.6.1).
RECETA: Hallar Im(T) = T(V) y el Rango r(T)
  1. Calcular las imágenes de todos los vectores de la base canónica: T(ē₁),...,T(ēₙ)
  2. T(V) = SG{T(ē₁),...,T(ēₙ)}
  3. Escalonar la matriz [T(ē₁)|...|T(ēₙ)] para eliminar las combinaciones lineales
  4. Las columnas pivote forman una base de T(V)
  5. r(T) = número de columnas pivote = número de filas no nulas en la forma escalonada
  6. Para encontrar la ecuación de T(V): si quedan filas nulas, la condición es que esa variable es libre
Ejemplo 5.6.2 del libro — P(x,y,z)=(x,y,0)
P(1,0,0)=(1,0,0), P(0,1,0)=(0,1,0), P(0,0,1)=(0,0,0)
T(ℝ³) = SG{(1,0,0),(0,1,0)} = {(x,y,z)|z=0} (plano xy)
Base: {(1,0,0),(0,1,0)} → r(P) = 2
5.7 — Núcleo, Nulidad y Teorema de la Dimensión
El teorema más importante del Capítulo 5
Definiciones
Def. 5.7.1 — Núcleo: N(T) = {v̄ ∈ V | T(v̄) = 0̄} ⊆ V

Def. 5.7.2 — Nulidad: n(T) = dim(N(T))
N(T) siempre es subespacio de V = dom(T) (Teorema 5.7.1). El núcleo está en el dominio, la imagen en el codominio.
RECETA: Hallar N(T) y la nulidad n(T)
  1. Plantear T(v̄) = 0̄ y escribir en forma matricial: [T]·v̄ = 0̄
  2. Escalonar la matriz [T] (sistema homogéneo)
  3. Expresar las variables dependientes en función de las libres
  4. N(T) = SG{vectores que salen de dar valor 1 a cada variable libre}
  5. n(T) = número de variables libres
Ejemplo 5.7.1 — P(x,y,z)=(x,y,0)
N(P) = {(x,y,z) | (x,y,0)=(0,0,0)} → x=0, y=0, z libre
N(P) = {(0,0,z) | z∈ℝ} = SG{(0,0,1)} → base β={(0,0,1)} → n(P)=1
Geométricamente: N(P) es el eje z
⭐ TEOREMA 5.7.2 — Teorema de la Dimensión (el más importante)
Teorema de la Dimensión
Para toda TL T: V→W con dim(V) finita:
dim(dom(T)) = n(T) + r(T) = Nulidad + Rango
Este teorema te permite hallar r(T) si conocés n(T), o viceversa. Siempre verificar que la suma dé dim(V).
Ejemplos del libro (5.7.4)
G: M₃ₓ₁→M₂ₓ₁, dim(dom)=3, r(G)=2 → n(G)=3−2=1
H: ℝ²→ℝ², H(x,y)=(x,0), n(H)=1 → r(H)=2−1=1
J: ℝ³→ℝ³, N(J)={(0,0,0)} → n(J)=0 → r(J)=3 → J(ℝ³)=ℝ³
Proposición 5.7.1 — Condiciones equivalentes
Condiciones equivalentes (T: V→W)
Las siguientes son todas equivalentes:
1. N(T) = {0̄}
2. n(T) = 0
3. dim(dom(T)) = r(T)
4. T transforma una base de dom(T) en una base de T(V)
Si N(T)={0̄} → T es inyectiva. Los vectores LD del dominio tienen imágenes LD.
5.8 — Isomorfismos
Definición · Inyectividad · Sobreyectividad · Teorema 5.8.1
Definición 5.8.1
T: V→W es isomorfismo de V sobre T(V) cuando T es TL y N(T)={0̄}.
PropiedadDefiniciónCondición en T
InyectivaT(ū)=T(v̄) ⟹ ū=v̄N(T) = {0̄}
SobreyectivaIm(T) = W (llega a todo el codominio)r(T) = dim(W)
BiyectivaInyectiva + SobreyectivaN(T)={0̄} y Im(T)=W
IsomorfismoTL + N(T)={0̄}N(T)={0̄}
RECETA: Demostrar que T ES isomorfismo
  1. Demostrar que T es TL (condición necesaria base)
  2. Hallar N(T) y demostrar que N(T) = {0̄} → T es inyectiva
  3. Si dim(V)=dim(W), por el Teorema de la dimensión: r(T)=dim(W) → T sobreyectiva → biyectiva
  4. Concluir: T es isomorfismo
Atajo: si dim(V)=dim(W) (finitas) y T es TL, basta demostrar UNA de las dos (inyectiva o sobreyectiva) para obtener la otra automáticamente.
Teorema 5.8.1 — El más importante de isomorfismos
Dos espacios vectoriales son isomorfos ⟺ tienen la misma dimensión.
En particular: ℝⁿ ≅ Mₙₓ₁ (son isomorfos, ambos tienen dim n).
Aplicación práctica del Teorema 5.8.1: para saber si V ≅ W simplemente comparar dimensiones.

🟡 Tarjetas de Memoria Rápida
Conceptos clave para no olvidar en el parcial · Errores más comunes

Tarjetas: Preguntas y Respuestas

¿Cuándo algo NO es subespacio? Forma más rápida.
Cuando el 0̄ no está. Sustituir (0,0,...,0) en la condición del conjunto. Si no la cumple → NO es SEV. Ejemplo: {(x,y) | x+y=1} → (0,0): 0+0=0≠1 → NO.
¿Diferencia entre N(T) e Im(T)?
N(T) = núcleo = está en el DOMINIO V = los vectores que T manda a 0̄. Im(T) = imagen = está en el CODOMINIO W = todos los resultados posibles de T.
Teorema Dimensión: T:ℝ⁵→ℝ³ y n(T)=2. ¿Cuánto vale r(T)? ¿Es sobreyectiva?
dim(V) = r(T)+n(T) → 5 = r(T)+2 → r(T)=3. Como dim(ℝ³)=3 y r(T)=3 → Im(T)=ℝ³ → SÍ es sobreyectiva.
¿Un sistema no homogéneo puede ser subespacio?
NUNCA. Si hay un término independiente h≠0, el vector (0,...,0) no satisface la ecuación, entonces 0̄ no está en el conjunto → no es subespacio. Proposición 3.4.2.
Tengo p vectores en ℝⁿ con p>n. ¿Qué concluyo sin calcular?
Automáticamente son LD (Teorema 3.5.2). No pueden ser base. No hace falta plantear el sistema.
Tengo k vectores LI en un SEV S con dim(S)=k. ¿Son base de S?
Sí automáticamente (Proposición 3.5.2, ítem 2). Si los vectores también pertenecen a S → ya es base. No hace falta verificar generación.
¿T(0̄)=0̄ implica que T es TL?
NO. T(0̄)=0̄ es condición NECESARIA pero no SUFICIENTE. Si T(0̄)≠0̄ → definitivamente NO es TL. Pero T(0̄)=0̄ no me asegura nada.
¿Cómo verifico que β es base ortonormal para un subespacio A ⊂ ℝⁿ?
1) Verificar que v̄ᵢ ∈ A (satisfacen la ecuación de A). 2) ⟨v̄ᵢ,v̄ⱼ⟩=0 para i≠j (ortogonal). 3) ‖v̄ᵢ‖=1 (unitarios). 4) |β|=dim(A). Listo.
Si T:V→W con dim(V)=dim(W) finita y T es TL, ¿qué basta demostrar para que sea isomorfismo?
Basta demostrar una sola: o N(T)={0̄} (inyectiva) o Im(T)=W (sobreyectiva). Ambas se implican mutuamente cuando las dimensiones son iguales.
¿Cuándo dos EV son isomorfos? ¿Cómo verificarlo?
Son isomorfos ⟺ dim(V) = dim(W). Solo comparar dimensiones (Teorema 5.8.1).
¿El conjunto {0̄, v̄₁, v̄₂} puede ser LI?
NUNCA. Por Lema 3.5.2: si 0̄ está en el conjunto → automáticamente LD. No importa quiénes sean v̄₁ y v̄₂.
Gram-Schmidt: cuando paro el proceso y qué significa.
Si en algún paso w̄ᵢ = 0̄, el proceso para. Significa que los vectores originales eran LD y no formaban una base → no se puede construir la base ortonormal a partir de ellos.

⚠️ Errores Más Comunes en el Parcial

Olvidar el paso de VERIFICACIÓN en Combinación Lineal: sustituir los cᵢ hallados y confirmar que da v̄. Ese paso suele tener puntos propios.
En la demostración de subespacio: arrancar directo con las 3 condiciones sin primero reescribir los elementos del conjunto en forma explícita (ese rewrite es el paso 1).
Confundir N(T) con Im(T): el núcleo está en el DOMINIO, la imagen en el CODOMINIO.
Gram-Schmidt: hacer todos los pasos perfectos pero olvidarse de unitarizar al final (‖w̄ᵢ‖ se calcula y se divide). Si el parcial pide base ortonormal hay que unitarizar.
Calcular las normas respecto a la base equivocada. ‖ū‖₂ con base canónica = √(Σxᵢ²). Con otra base β = √(Σcᵢ²) donde cᵢ son las coordenadas en β.
Concluir que T es isomorfismo solo porque dim(V)=dim(W). También hay que demostrar que T ES TL y que N(T)={0̄}.
Coordenadas con base ortonormal: el atajo cᵢ=⟨ū,v̄ᵢ⟩ SOLO vale si la base es ortonormal. Con base normal hay que resolver el sistema.
Producto vectorial: es anticonmutativo → ū×v̄ = −(v̄×ū). No confundir el orden.
